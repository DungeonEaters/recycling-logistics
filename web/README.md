# Panel admin web

## Requisitos
- Node.js 18+
- Backend FastAPI disponible en `http://localhost:8000`

## Variables de entorno
Copia `.env.example` a `.env` si necesitas cambiar la URL del backend.

```bash
VITE_API_URL=http://localhost:8000
```

## Ejecutar
```bash
npm install
npm run dev
```

El panel queda disponible en `http://localhost:5173`.
